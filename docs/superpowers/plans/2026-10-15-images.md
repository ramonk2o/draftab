# Images Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** image blocks in notes that point to web addresses (never stored files), coming in by typing, pasting and saving web pages.

**Architecture:** the official `@tiptap/extension-image` (block, not inline), extended in `src/images.ts` to keep only `src`/`alt`/`title`, accept only `http`/`https`, and render through a small node view that shows the address when the picture fails to load. Pure helpers in the same file are reused by markdown import, the clipboard text, page capture and the paste rule. An editor-only extension (`src/image-paste.ts`) turns a pasted image address into an image.

**Tech Stack:** TypeScript (strict), Tiptap 3.31.4, ProseMirror, Vitest (+ happy-dom for DOM tests), Vite.

**Spec:** `SPEC.md` ("Editor → Images", "Import a file as a note", "Copy for WhatsApp", "Character counts", "Saving web pages", "Known limitations") and the "Images" entry in `FEATURES.md`.

## Global Constraints

- Only `http`/`https` image addresses are stored; `data:` and other schemes are dropped.
- The note stores only `src`, `alt` and `title`; no `width`/`height`, no file.
- No new manifest permission.
- All `chrome.storage` access stays in `src/storage.ts` (this feature doesn't touch storage).
- Everything in English: code, comments, UI text, docs. Direct, readable code; no UI framework.
- `@tiptap/extension-image` must be the same version as the rest of Tiptap: `3.31.4`.
- `src/extensions.ts` is also bundled into the service worker (backup): nothing there may touch `document` at import time.

## Review Focus

1. Pasting a plain web link that isn't an image (`https://example.com/page`) must stay a link — test in Task 4 (`imageAddress` returns null).
2. Pasting an image address inside a list item or quote must not break the document — it stays a link; test in Task 4 (`pasteImageAddress` returns null inside a list).
3. A `.md` file with an image in the middle of a sentence must still import its text and formatting instead of falling back to plain text — test in Task 1.
4. A hard line break (Shift+Enter) copied as plain text must still become `\n` after the clipboard serializer gains an image case — test in Task 1 (`plainTextOf`).
5. Saved pages full of icons/tracking pixels must not fill the note with junk, and a page with only images still gives the "no text" error — tests in Task 2.

```ts
import type { Fragment, Node as PMNode } from '@tiptap/pm/model'
import { InputRule } from '@tiptap/core'
import { Image } from '@tiptap/extension-image'

// Image blocks (see "Images" in SPEC.md): the note stores only the picture's web address

// An http/https address (images with data:, relative or other addresses aren't kept)
export function isWebAddress(src: unknown): src is string {
  return typeof src === 'string' && /^https?:\/\/\S+$/i.test(src)
}

type ImageAttrs = { src?: string | null; alt?: string | null; title?: string | null }

// ![description](address "title"): how an image is written in markdown and in plain-text copies
export function imageMarkdown(attrs: ImageAttrs): string {
  const title = attrs.title ? ` "${attrs.title}"` : ''
  return `![${attrs.alt ?? ''}](${attrs.src ?? ''}${title})`
}

// Plain text of copied content: one line per block, an image as its markdown
// (passing a leaf function to textBetween replaces every leaf's own text, so hard breaks are kept here)
export function plainTextOf(fragment: Fragment): string {
  return fragment.textBetween(0, fragment.size, '\n', (leaf: PMNode) =>
    leaf.type.name === 'image' ? imageMarkdown(leaf.attrs) : (leaf.type.spec.leafText?.(leaf) ?? ''),
  )
}

export const DraftabImage = Image.extend({
  // Only the address, description and title: the picture shows at its natural size
  addAttributes() {
    return { src: { default: null }, alt: { default: null }, title: { default: null } }
  },

  // An <img> (pasted HTML, saved pages) becomes an image only with a web address
  parseHTML() {
    return [{ tag: 'img[src]', getAttrs: (el) => (isWebAddress((el as HTMLElement).getAttribute('src')) ? null : false) }]
  },

  // ![description](url) typed in the note: only with a web address
  addInputRules() {
    return (this.parent?.() ?? []).map(
      (rule) => new InputRule({ find: rule.find, handler: (props) => (isWebAddress(props.match[3]) ? rule.handler(props) : null) }),
    )
  },

  renderMarkdown: (node) => imageMarkdown(node.attrs ?? {}),

  // The picture, or its address in a box when it can't load (gone from the site, no internet)
  addNodeView() {
    return ({ node }) => {
      const dom = document.createElement('div')
      dom.className = 'image-block'
      const img = document.createElement('img')
      img.draggable = false // blocks move with the handle
      img.src = node.attrs.src
      if (node.attrs.alt) img.alt = node.attrs.alt
      if (node.attrs.title) img.title = node.attrs.title
      img.addEventListener('error', () => {
        const box = document.createElement('div')
        box.className = 'image-broken'
        box.textContent = node.attrs.src
        img.replaceWith(box)
      })
      dom.append(img)
      return { dom }
    }
  },
})
```

Note: the `inputRegex` groups in the official extension are `[full, markdown, alt, src, title]`, so `match[3]` is the address. If `Image` isn't a named export in 3.31.4, use the default import.

```ts
// An image inside a line of text (or a list item), or with an address that isn't http/https,
// stays as its ![description](address) text; only an image on a line of its own becomes a block
function imagesToText(node: JSONContent, inText = false): JSONContent {
  if (node.type === 'image' && (inText || !isWebAddress(node.attrs?.src))) {
    const text: JSONContent = { type: 'text', text: imageMarkdown(node.attrs ?? {}) }
    return inText ? text : { type: 'paragraph', content: [text] }
  }
  if (!node.content) return node
  const isTextBlock = node.type === 'paragraph' || node.type === 'heading'
  const content = node.content.map((child) => imagesToText(child, isTextBlock))
  return { ...node, content: isTextBlock ? mergeTexts(content) : content }
}

// Neighboring pieces of text with the same formatting become one
function mergeTexts(content: JSONContent[]): JSONContent[] {
  const merged: JSONContent[] = []
  for (const piece of content) {
    const last = merged[merged.length - 1]
    const sameMarks = JSON.stringify(last?.marks ?? []) === JSON.stringify(piece.marks ?? [])
    if (last?.type === 'text' && piece.type === 'text' && sameMarks) {
      merged[merged.length - 1] = { ...last, text: (last.text ?? '') + (piece.text ?? '') }
    } else {
      merged.push(piece)
    }
  }
  return merged
}
```

```ts
// The pasted text when it's only an image's web address (ends in an image extension,
// a ?query or #fragment after it is fine); null otherwise
export function imageAddress(text: string): string | null {
  const address = text.trim()
  return /^https?:\/\/\S+\.(png|jpe?g|gif|webp|svg|avif)([?#]\S*)?$/i.test(address) ? address : null
}

// Pasting an image address alone on an empty line outside lists and quotes: the image goes in
// above the line and the cursor stays on it. null = paste normally (the address becomes a link)
export function pasteImageAddress(state: EditorState, text: string): Transaction | null {
  const src = imageAddress(text)
  const { $from, empty } = state.selection
  const onEmptyLine = empty && $from.depth === 1 && $from.parent.type.name === 'paragraph' && $from.parent.content.size === 0
  if (!src || !onEmptyLine) return null
  return state.tr.insert($from.before(), state.schema.nodes.image.create({ src })).scrollIntoView()
}
```

```ts
  // Before the link extension, which would turn the address into a link

            return true
```
