Backup

Um arquivo JSON com todas as notas e configurações. Cada nota vai também em markdown, para dar para ler o arquivo sem o Draftab.

Importar substitui todas as notas atuais pelas do arquivo.

Backup automático

Salva um backup em Downloads/draftab-backups/ sem perguntar, só quando alguma nota mudou desde o último. Funciona mesmo com a aba fechada, enquanto o Chrome estiver aberto.

Se o Chrome estiver configurado para "Perguntar onde salvar cada arquivo", ele vai abrir essa pergunta a cada backup automático.
