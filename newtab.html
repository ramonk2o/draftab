Settings

    Backup

    A JSON file with all notes and settings. Each note also goes in markdown, so the file can be read without Draftab.

    Importing replaces all current notes with the ones in the file.

    Automatic backup

    Saves a backup to Downloads/draftab-backups/ without asking, only when some note changed since the last one. Works even with the tab closed, as long as Chrome is open.

    If Chrome is set to "Ask where to save each file before downloading", it will ask on every automatic backup.

    Appearance

    Delete all notes

    Removes every note from this browser. This can't be undone; export a backup first if you want to keep anything. Settings are kept.
